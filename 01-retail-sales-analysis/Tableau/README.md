# Tableau Dashboard — Retail Sales Performance

This folder contains the Tableau dashboard documentation and supporting files for the Retail Sales Performance Analysis project.

## Dashboard Overview

The Retail Sales Performance Dashboard provides an interactive view of retail business performance through revenue, sales quantity, product and regional analysis.

## Dashboard Components

- Total Revenue
- Total Units Sold
- Revenue by Product
- Sales by Region
- Customer Revenue Analysis

## Workbook Contents

The Tableau workbook contains 10 worksheets and one consolidated dashboard.

## Interactive Features

- Region dropdown filter to explore sales performance by geographical region.

## Documentation

Refer to `Retail_Sales_Analysis_Tableau_Dashboard_Documentation.md` for the detailed explanation of the data model, calculated fields, worksheets, dashboard design and business insights.
