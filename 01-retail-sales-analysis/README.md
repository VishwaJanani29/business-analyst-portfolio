# Retail Sales Performance Analysis

## 1. Project Overview

This project analyses retail sales data to understand revenue performance, product sales, regional distribution and customer purchasing patterns.

Using SQL for data analysis and Tableau for data visualisation, the project demonstrates how raw retail transaction data can be transformed into meaningful business insights.

## 2. Business Objectives

- Evaluate overall retail revenue and sales volume.
- Identify products contributing to revenue.
- Analyse sales distribution across regions.
- Understand customer-level revenue contribution.
- Present key findings through an interactive Tableau dashboard.

## 3. Tools & Technologies

- **SQL:** Data querying, aggregation, joins and business analysis.
- **Tableau:** Data visualisation and dashboard development.
- **Dataset:** Retail sales data comprising Customers, Products and Orders tables.
